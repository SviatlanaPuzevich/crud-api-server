# Simple REST API Server

A simple Node.js REST API server for managing users.  
The project implements basic CRUD operations using pure Node.js without frameworks.

---

## Endpoints Overview

### `GET /api/users`
- Returns **200 OK** and a list of all users.

### `GET /api/users/{userId}`
- Returns **200 OK** and the user record with `id === userId`.
- Returns **400 Bad Request** if `userId` is not a valid UUID.
- Returns **404 Not Found** if no record with `id === userId` exists.

### `POST /api/users`
- Creates a new user record.
- Returns **201 Created** and the created user.
- Returns **400 Bad Request** if required fields are missing.

### `PUT /api/users/{userId}`
- Updates an existing user.
- Returns **200 OK** and the updated record.
- Returns **400 Bad Request** if `userId` is invalid.
- Returns **404 Not Found** if the record doesn’t exist.

### `DELETE /api/users/{userId}`
- Deletes an existing user.
- Returns **204 No Content** if the user is deleted.
- Returns **400 Bad Request** if `userId` is invalid.
- Returns **404 Not Found** if the record doesn’t exist.

## User Model

Users are stored as objects with the following properties:

| Field     | Type           | Required | Description |
|------------|----------------|-----------|--------------|
| `id`       | string (UUID)  | Yes       | Unique identifier generated by the server |
| `username` | string         | Yes       | User’s name |
| `age`      | number         | Yes       | User’s age |
| `hobbies`  | string[]       | Yes       | Array of hobbies (can be empty) |

Example:
```json
{
  "id": "db5b6794-c3f1-4011-8bcd-9aa9d5d4d333",
  "username": "John Doe",
  "age": 23,
  "hobbies": ["surfing"]
}
```


##  Environment Configuration

All required environment variables are listed in **`.env.example`**.  
Create a `.env` file and fill in the necessary values before starting the server.

---

##  Running the Server

### Development mode
```bash
npm run start:dev
```

### Production mode
```bash
npm run start:prod
```

### Cluster mode
```bash
npm run start:cluster
```

The server uses **webpack** for production builds.

## Testing

Manual REST requests are available in **`/src/requests`**.
You can test endpoints with these files using VS Code REST Client or similar tools.

Make sure:

The server runs on the same port as defined in the **`.rest`** files (or update them if needed).

The **`/src/controllers/userController`** the array of users includes at least one valid user for manual tests:
```json
{
"id": "db5b6794-c3f1-4011-8bcd-9aa9d5d4d333",
"username": "John Doe",
"age": 23,
"hobbies": ["surfing"]
}
```


To run automated tests:
```bash
npm test
```

The test suite uses **Jest** and **Supertest**.
If you previously added manual users, clear the user store before running tests.
